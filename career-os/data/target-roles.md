## Role Definitions

Use these to guide the Job Research Agent when searching. These are the keywords that define each role.

### Program Manager
Search terms: "program manager," "senior program manager," "staff program manager"
Must-haves: cross-functional delivery, stakeholder management, roadmaps, OKRs or goals frameworks

### Technical Program Manager
Search terms: "technical program manager," "TPM," "engineering program manager"
Must-haves: engineering org experience, technical credibility, systems understanding
Nice-to-haves: AI/ML, infrastructure, distributed systems

### AI Systems Architect
Search terms: "AI systems architect," "AI program manager," "AI operations," "LLM systems," "AI product manager"
Must-haves: AI/LLM workflow design, systems thinking, cross-functional AI delivery

### Operations Manager
Search terms: "operations manager," "senior operations manager," "head of operations," "director of operations"
Must-haves: process design, team management, metrics, operational efficiency
